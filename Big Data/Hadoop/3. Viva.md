# Viva Voce / Interview Questions and Answers

## HDFS (Hadoop Distributed File System)

### Q1. What is HDFS?

**Answer:**
HDFS (Hadoop Distributed File System) is the distributed storage system of Hadoop used to store large volumes of data across multiple machines while providing fault tolerance and high availability.

---

### Q2. Why is HDFS used?

**Answer:**
HDFS is used because it can:

* Store very large datasets
* Provide fault tolerance through replication
* Scale horizontally by adding more machines
* Support high-throughput data access

---

### Q3. What are the main components of HDFS?

**Answer:**

1. **NameNode**

   * Maintains metadata of files and directories.

2. **DataNode**

   * Stores actual data blocks.

3. **Secondary NameNode**

   * Assists NameNode by periodically merging metadata files.

---

### Q4. What is a block in HDFS?

**Answer:**
A block is the smallest unit of storage in HDFS. Large files are divided into blocks and distributed across DataNodes.

Default block size:

* Hadoop 2.x → 128 MB
* Older versions → 64 MB

---

### Q5. What is replication in HDFS?

**Answer:**
Replication means storing multiple copies of a data block on different DataNodes to ensure fault tolerance.

Default replication factor = **3**

---

### Q6. Which command is used to create a directory in HDFS?

**Answer:**

```bash
hdfs dfs -mkdir -p /directory_name
```

---

### Q7. Which command is used to upload a file to HDFS?

**Answer:**

```bash
hdfs dfs -put localfile hdfs_directory
```

---

### Q8. Difference between -put and -copyFromLocal?

**Answer:**
Both upload files from local system to HDFS.

```bash
hdfs dfs -put
```

and

```bash
hdfs dfs -copyFromLocal
```

perform similar operations.

---

### Q9. How do you display the contents of a file in HDFS?

**Answer:**

```bash
hdfs dfs -cat filename
```

---

### Q10. How do you rename a file in HDFS?

**Answer:**

```bash
hdfs dfs -mv oldname newname
```

---

### Q11. How do you download a file from HDFS?

**Answer:**

```bash
hdfs dfs -get hdfsfile localpath
```

or

```bash
hdfs dfs -copyToLocal hdfsfile localpath
```

---

### Q12. How do you list files in an HDFS directory?

**Answer:**

```bash
hdfs dfs -ls directory
```

---

### Q13. How do you change file permissions in HDFS?

**Answer:**

```bash
hdfs dfs -chmod permission filename
```

Example:

```bash
hdfs dfs -chmod 640 student_data.txt
```

---

### Q14. What does permission 640 mean?

**Answer:**

| User   | Permission    |
| ------ | ------------- |
| Owner  | Read + Write  |
| Group  | Read          |
| Others | No Permission |

Symbolic form:

```text
rw-r-----
```

---

### Q15. What does permission 740 mean?

**Answer:**

| User   | Permission           |
| ------ | -------------------- |
| Owner  | Read, Write, Execute |
| Group  | Read                 |
| Others | No Permission        |

Symbolic form:

```text
rwxr-----
```

---

### Q16. How can you check the size of a file in HDFS?

**Answer:**

```bash
hdfs dfs -du -h filename
```

---

### Q17. What is fault tolerance in HDFS?

**Answer:**
Fault tolerance is the ability of HDFS to continue functioning even if one or more DataNodes fail.

---

### Q18. What happens if a DataNode fails?

**Answer:**
The NameNode automatically retrieves data from another replica stored on different DataNodes.

---

## Apache Hive

### Q19. What is Apache Hive?

**Answer:**
Apache Hive is a data warehouse tool built on Hadoop that allows users to query and analyze large datasets using SQL-like language called HiveQL.

---

### Q20. What is HiveQL?

**Answer:**
HiveQL is a SQL-like query language used in Hive to create tables, insert data, and perform analysis.

---

### Q21. Why is Hive used?

**Answer:**

* Data warehousing
* Data summarization
* Batch processing
* Big data analytics

---

### Q22. Difference between Hive and Traditional RDBMS?

| Hive                  | RDBMS                     |
| --------------------- | ------------------------- |
| Handles huge datasets | Handles moderate datasets |
| Batch processing      | Real-time processing      |
| Runs on Hadoop        | Runs on database servers  |
| Schema-on-read        | Schema-on-write           |

---

### Q23. What are Hive tables?

**Answer:**
Hive tables are logical structures used to organize data stored in HDFS.

---

### Q24. What is partitioning in Hive?

**Answer:**
Partitioning divides table data into separate directories based on partition column values.

Example:

```sql
PARTITIONED BY(region STRING)
```

---

### Q25. Why is partitioning used?

**Answer:**

* Faster queries
* Reduced data scanning
* Better performance

---

### Q26. Which tables in your assignment use partitioning?

**Answer:**

1. orders
2. sales_data

---

### Q27. What is the advantage of querying a partitioned table?

**Answer:**
Hive scans only the required partition instead of the entire table, reducing execution time.

---

### Q28. What is bucketing in Hive?

**Answer:**
Bucketing divides table data into a fixed number of files using a hash function on a specified column.

---

### Q29. Which tables in your assignment use bucketing?

**Answer:**

1. department_employees
2. student_marks
3. movie_rentals
4. employee_data

---

### Q30. What is the syntax for bucketing?

**Answer:**

```sql
CLUSTERED BY(column_name)
INTO n BUCKETS
```

Example:

```sql
CLUSTERED BY(emp_id)
INTO 4 BUCKETS
```

---

### Q31. Difference between Partitioning and Bucketing?

| Partitioning                 | Bucketing                   |
| ---------------------------- | --------------------------- |
| Based on column values       | Based on hash function      |
| Creates directories          | Creates files               |
| Dynamic number of partitions | Fixed number of buckets     |
| Reduces data scanning        | Improves joins and sampling |

---

### Q32. What is the formula used in bucketing?

**Answer:**

```text
Bucket Number = HASH(Column Value) % Number of Buckets
```

---

### Q33. Why do we use bucketing?

**Answer:**

* Faster joins
* Efficient sampling
* Better query optimization
* Balanced data distribution

---

### Q34. Which Hive query displays records from a specific partition?


---

### Q35. Which query calculates total quantity city-wise?

**Answer:**

```sql
SELECT city,
SUM(quantity)
FROM sales_data
GROUP BY city;
```

---

### Q36. Which query calculates average marks subject-wise?

**Answer:**

```sql
SELECT subject,
AVG(marks)
FROM student_marks
GROUP BY subject;
```

---

### Q37. Which aggregate functions are used in your assignments?

**Answer:**

1. SUM()
2. AVG()

---

### Q38. What is GROUP BY used for?

**Answer:**
GROUP BY groups rows having the same values in specified columns and allows aggregate calculations.

---

### Q39. What is the purpose of ORDER BY?

**Answer:**
ORDER BY sorts the result set in ascending or descending order.

Example:

```sql
SELECT *
FROM department_employees
ORDER BY emp_id;
```

---

### Q40. What is the difference between WHERE and HAVING?

**Answer:**

| WHERE                   | HAVING                 |
| ----------------------- | ---------------------- |
| Filters rows            | Filters groups         |
| Applied before GROUP BY | Applied after GROUP BY |

---
